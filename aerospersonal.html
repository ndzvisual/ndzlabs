NDZ DEVELOPMENT SYSTEM · CASE 01

AerOS Personal

A portable, declarative contract system for governing product development.

What This Is

This is NOT a conventional software application. It is a collection of declarative artifacts — contracts, agent definitions, workflows, policies, capabilities, validators, protocols, and state definitions — that can be interpreted by a compatible execution environment (OpenCode, Codex, Claude Code, or another agentic system).

What This Is NOT

  • NOT a compiled application
  • NOT an LLM integration
  • NOT an IDE plugin
  • NOT dependent on any specific programming language, LLM, or execution environment

Governance

This system is governed by its own contracts. The execution environment (currently OpenCode) provides capabilities but has no authority over the system.

Authority hierarchy: Human → Orchestrator → Contract/Policy → Agent → Tools
